

📚 Library Management System (Python)

A simple Library Management System built in Python to manage books, users, and borrowing records.
The project focuses on clean logic, data handling, and program structure, rather than UI frameworks.


---

🎯 Purpose of the Project

This project was built to:

Practice core Python programming

Implement real-world business logic

Understand state management (books, users, transactions)

Build a complete system from scratch without heavy libraries


It serves as a foundational software project, complementing more math- and simulation-heavy work.


---

🧠 Core Features

Add, remove, and update books

Register and manage users

Issue and return books

Track availability status

Prevent invalid operations (e.g. issuing unavailable books)



---

🏗️ System Design (High Level)

The system models a real library using structured logic:

Books → title, author, availability

Users → name, ID, issued books

Transactions → issue / return flow


The program maintains state internally and updates it based on user actions.
